# Linked Grid Resize: ручная тестовая сборка Windows x64

Это портативный тестовый ZIP, не релиз. По умолчанию `LinkedGridResize=0`.
Не запускайте две копии AltSnap одновременно.

1. Откройте **Actions → Linked Grid Windows x64 test ZIP → Run workflow**.
   Выберите ветку `feat/linked-grid-resize` и запустите. В завершённом run
   скачайте артефакт `AltSnap-linked-grid-win64-test` (хранится 7 дней).
   Если workflow не появляется в Actions, см. ограничение ниже.
2. Загрузка артефакта даст архив GitHub, внутри которого лежит
   `AltSnap-linked-grid-win64-test.zip`. Извлеките внутренний ZIP в отдельную
   папку, например `C:\AltSnap-linked-grid-test`. Не заменяйте установленный AltSnap.
3. Перед распаковкой проверьте SHA-256 внутреннего ZIP в PowerShell:
   `Get-FileHash .\AltSnap-linked-grid-win64-test.zip -Algorithm SHA256`.
   Сравните результат со строкой `sha256sum` в логе шага **Package and inspect
   portable ZIP** того же run. Хэш относится именно к внутреннему ZIP.
4. Закройте обычный AltSnap через значок в трее. В новой папке измените
   `AltSnap.ini`: в `[General]` установите `LinkedGridResize=1` и
   `StickyResize=1`. Для контура используйте `FullWin=0`, для изменения
   размеров во время движения `FullWin=1`. При `StickyResize=1` удерживайте
   Shift **до** начала resize. Затем запустите `AltSnap.exe` из новой папки.
5. Разместите четыре обычных окна строгой сеткой 2×2 на одном мониторе.
   Проверьте внутренний угол, mouse-up и Escape при `FullWin=0` и `1`;
   повторите на втором мониторе. Проверьте обычный move/resize при
   `LinkedGridResize=0`. Прекратите тест при задержке ввода, неожиданном
   перемещении окна или частично изменённой сетке.
6. Для выхода закройте тестовый AltSnap через трей (при необходимости через
   Диспетчер задач). Можно удалить отдельную папку и снова запустить обычный
   AltSnap. Локальный INI удерживает настройки теста в этой папке.

GitHub может показывать ручной `workflow_dispatch` только для workflow,
присутствующего в default branch. В этом проекте main намеренно не меняется.
Если GitHub не даёт запустить workflow из ветки, ZIP нужно собрать локально
или согласовать отдельный способ запуска; не считайте артефакт уже созданным.
