# Диагностика Maximize в Windows 10 x64

Это эксперимент, не исправление AltSnap. Основной Maximize не изменён.
Закройте AltSnap, чтобы освободить Ctrl+Alt+W. В командной строке запускайте
по одному варианту из каталога portable-сборки:

```
maximize-diagnostic.exe syscommand
maximize-diagnostic.exe async
maximize-diagnostic.exe show
maximize-diagnostic.exe placement
```

Каждый вариант регистрирует Ctrl+Alt+W (переключить), Ctrl+Alt+I (снимок
состояния активного окна), Ctrl+Alt+Q (завершить). Автоповтор клавиши отключён;
отдельные нажатия W при удержании Ctrl+Alt разрешены. INI не читается и не меняется.
Цель захватывается из foreground один раз на нажатие; отложенных операций в
инструменте нет. API Windows с асинхронной обработкой всё равно может выполнить
запрос позже. HWND не является долговечной идентичностью: уничтожение и повторное
использование HWND между проверкой и API полностью исключить таким способом нельзя.

Для каждого режима откройте Explorer в ячейке сетки, затем закройте AltSnap.
Сфокусируйте Explorer, удерживайте Ctrl+Alt, нажмите W. Проверьте немедленную
обычную максимизацию, заголовок и кнопки. Отпустите только W и нажмите снова:
ожидается восстановление в прежнюю ячейку, без перемещения соседей. Нажмите I
после визуального завершения операции. Повторите быстро, со сменой фокуса и
закрытием цели, на втором мониторе и в других приложениях (например Notepad).
Проверьте отдельно обычную максимизацию без Ctrl через штатную кнопку.
Если syscommand включает fullscreen, F11 должен вывести из него перед следующим
экспериментом. Запишите версию Windows, режим, результат, вывод программы.

Выбор API:
- WM_SYSCOMMAND передаёт команду приложению; Explorer может трактовать Ctrl особо.
- ShowWindowAsync запрашивает show-state без явной отправки SC_MAXIMIZE; не ждёт
  чужой UI-поток. Это главный кандидат, но реальный Explorer ещё не проверен.
  Успех означает принятие запроса, а IsZoomed до завершения может быть устаревшим.
- ShowWindow использует show-state синхронно и может ждать чужой поток; его BOOL
  означает прежнюю видимость, а не успех. Это диагностический вариант.
- SetWindowPlacement сохраняет прочитанное placement и меняет showCmd, но также
  применяет placement/flags; возможны эффекты геометрии и мониторов.

Нет ожидания Ctrl, таймеров, Sleep или синтетических клавиш. Пока нет подтверждения
Explorer, ни один альтернативный API не включён в основной путь AltSnap.
Linux-тесты и успешная кросс-сборка не подтверждают GUI-поведение Windows.
